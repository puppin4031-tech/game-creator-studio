# 펫 합체 성장과 거점 수호

## 목표
산책으로 알을 얻고 → 집에서 부화시키고 → 중복 펫을 합체하고 → 성장한 펫이 거점을 지키는 흐름을 만듭니다. 기존 지도·원정·제단은 유지하며, 실시간 AI 호출 없이 구현합니다.

## 1. 합체 성장
- 부화한 펫은 모두 **Lv.1**입니다. 기존에 부화한 펫도 빠짐없이 Lv.1로 이어집니다.
- **같은 종류·같은 레벨 2마리 → 다음 레벨 1마리**입니다. Lv.2 두 마리로 Lv.3, 이후에도 같은 방식입니다.
- 첫 버전의 상한은 **Lv.5**로 제안합니다. Lv.5 한 마리에는 Lv.1 16마리가 필요하므로 충분한 수집 목표가 됩니다.
- 합체는 100% 성공하며 추가 재료·유료 비용이 없습니다. 확인창에서 사라지는 두 마리와 결과를 보여주고, 잠근 펫은 합체에 사용하지 않습니다.
- 레벨마다 기본 체력·공격력이 25%씩 선형 증가합니다. 전투 경험치로 레벨이 오르지는 않아 산책과 알 수집의 의미를 유지합니다.

## 2. 거점에서 살아 움직이는 펫
- 부화하면 보유 목록에 추가되고, 수호 자리가 비어 있으면 자동 배치합니다.
- **수호 펫 최대 3마리**, 나머지는 거점의 펫 목록에서 대기합니다. 목록에는 모습·레벨·체력·상태·동일 펫 수와 합체 가능 여부를 표시합니다.
- 배치된 펫은 거점 안에서 짧게 걷고 멈추며 어슬렁거립니다. 이동 방향에 맞춰 좌우 반전합니다.
- 관리자에서 올린 펫 스프라이트를 그대로 사용합니다. 별도 공격 시트가 없어도 돌진·피격·타격음·피해 숫자로 전투가 보이게 합니다.
- 별도의 지도 하단 패널을 추가하지 않고 **기존 거점창에 펫 탭**을 넣습니다.

## 3. 무차별 공격 대신 거점 방어
- **실제 다른 플레이어와 방문자는 공격하거나 약탈하지 않습니다.** 집 주변 위치 노출이나 일방적인 피해 없이 함께 즐길 수 있어야 합니다.
- 첫 버전은 **짐승 대상 PvE 수호**입니다. 거점 보호 경계에 접근한 적대적 짐승만 상대하며, 펫이 거점 밖으로 끝없이 추격하지 않습니다.
- 기존 거점 안전 규칙은 유지합니다. 거점 안 자원이나 무해한 동물에 자동 공격을 걸지 않습니다.
- 전투는 기존 몹 체력·전리품 처리를 공유하고, 플레이어·원정과 같은 적을 잡아도 보상이 중복되지 않게 합니다.
- 체력이 25% 이하가 되면 거점으로 물러나 휴식합니다. 펫은 죽거나 사라지지 않고, 휴식 60초 뒤 체력을 회복합니다.
- 처치한 전리품은 거점 창고로 들어가고 펫 탭에 최근 수호 기록을 남깁니다. 자동 방어 전리품은 **하루 10회**까지만 지급하고, 이후에도 방어는 계속합니다.
- 화면이 열려 있고 거점 주변이 활성화된 동안만 전투를 처리합니다. 앱을 닫아둔 시간에 전리품을 무한 생성하지 않습니다.
- 사람을 상대하는 재미는 이후 **게임 속 NPC 도적의 선택형 습격 이벤트**로 확장할 수 있습니다. 실제 유저 약탈과 NPC 습격은 이번 범위에서 제외합니다.

## 기술 구현
- 개별 펫에 고유 ID·종류·레벨·체력·배치·잠금 상태를 저장합니다. 기존 `babyDinos`를 한 번만 변환하고 현재 저장·클라우드 동기화를 재사용합니다.
- 합체·능력치·회복·보상 한도를 순수 규칙 모듈로 분리하고, 거점 접근 및 GPS 허용 여부는 기존 실내/실외 규칙을 따릅니다.
- 기존 몹 피해·처치 경로에 수호 전투를 연결해 중복 처치와 중복 보상을 차단합니다. 주변 사람의 저장·실시간 위치는 변경하지 않습니다.
- 순찰은 배치된 세 마리만 처리하고, 화면 비활성 시 중단하여 모바일 부담을 제한합니다.
- 관리자 펫 등록과 대기 스프라이트 연결은 유지합니다. 지도·엔진 교체나 새 AI 생성 비용은 없습니다.

## 검증
- 부화 Lv.1, Lv.1 두 마리 → Lv.2, Lv.2 두 마리 → Lv.3, 종류/레벨 불일치 차단, 잠금 차단, Lv.5 상한을 각각 테스트합니다.
- 기존 펫 보존·새로고침 복원·배치 3마리·체력 증가·휴식·일일 보상 제한·중복 처치 방지를 테스트합니다.
- 모바일과 데스크톱에서 부화 → 펫 목록 → 합체 확인 → 지도 순찰 → 짐승 방어 → 창고 전리품 → 저장 복원 흐름을 확인합니다. 기기별 진동·스피커 청취는 브라우저 확인과 구분해 보고합니다.
