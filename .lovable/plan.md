# 서바이벌 가이드북 추가

## 목표
게임 상단 메뉴(나가기/설정 있는 곳)에 "가이드" 버튼을 추가하고, 실제 게임 시스템과 일치하는 인게임 도감을 만든다.

## 가이드북 목차 (실제 게임 규칙 기반)
1. **게임 소개** — 실제 GPS로 걸어다니며 채집·사냥·연구하는 고대 생존 게임. 위치 기반 플레이 설명.
2. **거점** — 모닥불 → 움집 → 목책 → 전진기지 발전, 거점 안 회복·보관·연구, 거점 공사(실시간 타이머).
3. **GPS와 이동** — GPS 신호 품질, 상호작용 반경(10m/기술로 확장), 속도 제한, 위치 오차 안내.
4. **채집과 자원** — 나무/바위/약초/흙, 도구 필요(도끼·곡괭이), 한 번 탭하면 자동 반복, 배낭 무게와 이공간 주머니.
5. **사냥과 전투** — 짐승 어그로(10m), 도망치면 원위치, 무기/방어구, 공격 스킬 3종(돌팔매 연타·포효·불씨 뿌리기)과 스킬 레벨.
6. **기술 연구** — 재료 + 실제 시간(30분~24시간), 여러 개 동시 연구, 완료 시 빨간 점 → 습득, 기술 레벨 1~5(공격력·방어력·최대 체력·회복량 강화).
7. **레벨과 성장** — 경험치, 캐릭터 레벨.
8. **무기와 장비** — 제작, 발명(제단에서 재료 조합 → AI 이름짓기, 실제 능력치 반영).
9. **펫과 동료** — 길들이기, 원정대(자동사냥 관찰), 정찰 보고서.
10. **NPC와 랜드마크** — 만물상(다이소), 샤먼(지하철역), 샘터(카페), 말린고기(패스트푸드) 등 장소 힌트, 쿨다운 규칙.
11. **제단** — 개인 제단(거점, 발명) vs 신성한 제단(고인돌 성소, 멜키체덱, 제사·신성력, 성소 네트워크 235곳, 황금 결계).
12. **집에서 할 일** — 원정대, 정찰 보고, 연구/공사 타이머, 알림.
